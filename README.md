# Skillora Academy 🎓

A modern, responsive online learning academy website built with HTML, CSS, Bootstrap, and JavaScript.

Skillora Academy provides a clean and user-friendly interface for exploring educational courses, viewing course details, and registering interest in learning programs.

## ✨ Features

* **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.
* **Course Catalog:** Browse six courses across different learning categories.
* **Course Filtering:** Filter courses by development, programming, design, and databases.
* **Dynamic Course Details:** View course descriptions, duration, difficulty level, learning outcomes, and requirements.
* **Course Registration Form:** Complete a client-side form with input validation and automatic course selection.
* **Interactive Navigation:** Navigate between the home page, course catalog, course details, and contact page.
* **Modern UI:** Clean layouts, Bootstrap components, and Bootstrap Icons.
* **Dynamic Footer:** Automatically displays the current year.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* JavaScript (Vanilla JavaScript)

## 🚀 Getting Started

No build tools or package installation are required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For the best development experience, use Visual Studio Code with the Live Server extension.

## 📝 Project Notes

* This project is a front-end demonstration of an online learning academy website.
* The registration form performs client-side validation only.
* Registration information is not submitted to a server or stored in a database.
* Course information is provided for demonstration purposes.
* Some visual assets are loaded from external sources.
